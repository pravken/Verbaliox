# «Пульт встреч»: перенос нового вида в программу

Новый вид собран в примерочной (вариант Б, «Пульт встреч»). В программу он входит по этапам; каждый этап —
одна бета (`0.8.27-beta.N`…), и после каждого программа работает целиком: старое убирается только тогда,
когда новое его заменило.

## Что меняется

| Было | Станет |
|---|---|
| Боковая панель шириной 312 px: железо, модели, дерево записей | Полоса разделов слева (72 px, в узком окне 56 px — одни значки): Сегодня, Обзор, Записи, Задачи, Люди, Ассистент; внизу «Словарь», «Очередь» и «Настройки» |
| Верхняя полоса разделов (`#app-bar`) | Полоса встречи сверху: «Свободно», «Скоро», «Идёт без записи», «Идёт запись», «Закончилась», «Итоги готовы» — с главной кнопкой своего состояния |
| «Главная» (виджеты и день) | «Сегодня» — календарь (день, неделя, месяц) и карточки дня справа; «Обзор» — аналитика периода с виджетами |
| Список записей в боковой панели | Раздел «Записи»: таблица, компактно, карточки, папки; колонки на выбор; поиск с найденными местами |
| Железо и модели в боковой панели | Строка состояния: индикатор нагрузки с окном «что в памяти»; «Очередь» — что выполняется и что ждёт |
| Открытая запись с вкладками в верхней полосе | Экран записи: заголовок с «Записи / название», «Итоги» первыми, плеер внизу; ссылки «▶ 06:12» из итогов; расшифровка вместе с плеером |

## Этапы

1. **Каркас.** Полоса разделов слева с Ctrl+1…6 и значками дел; «Очередь» (из `/api/queue` и
   `meeting_holds()`); строка состояния с индикатором нагрузки. Боковая панель записей пока остаётся
   внутри раздела «Записи». Верхняя полоса уходит.
2. **Полоса встречи.** Состояние из календаря, звонков и записи (`meeting_guard`, `calendar`, `recording`);
   «Подключиться», «Записать с начала встречи», «Отметить момент», «Открыть итоги».
3. **Сегодня и Обзор.** «Главная» делится на два раздела; виджеты и «Настроить» переходят в «Обзор».
4. **Записи.** Таблица с колонками, виды, поиск по тексту с местами; дерево папок — вид «Папки».
5. **Экран записи и плеер.** Итоги первыми со ссылками на моменты, расшифровка вместе с плеером,
   клавиши плеера, разгруженный плеер.
6. **Задачи, Люди, Ассистент, Настройки** — по примерочной. Словарь переезжает из «Настройки → Словарь» в
   свой раздел внизу полосы: добавление со словами-вариантами и группой, фильтр по группам, сколько записей
   со словом, включение по одному, «Предложено из записей» (`offerDictionaryWords`), «Исправлять похожие по
   звучанию слова». Фичи остаются в «Обзоре».
7. **Вид**: одна шкала шрифтов, единые анимации, пустые экраны, заготовки при загрузке, светлая тема.

## Правила (из CLAUDE.md)

- Тексты — ключи в `static/i18n.js` (ru и en), серьёзный тон без разговорных слов.
- Однотипные элементы держат места; без inline-обработчиков (`data-click`); новые классы — `npm run vendor`.
- Каждый этап: тесты, `check.sh`, сценарии для нового (`tests/ui/scenarios.mjs`), скриншоты тёмной темы и
  узкого окна 1100.
